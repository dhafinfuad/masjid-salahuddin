# User UI & Component Preferences — Masjid Salahuddin

## Aturan Khusus Desain & Komponen (User Mandate)

1. **DILARANG KERAS Menggunakan Badge "Hari Ini" atau Badge Serupa**:
   - Jangan pernah menambahkan badge teks penanda waktu seperti `Hari Ini` pada jadwal, kartu kegiatan, atau daftar kalender.
   - Untuk membedakan hari ini atau baris aktif: tempatkan baris di posisi paling atas (Row #1) dan gunakan latar belakang/border halus yang sudah ada tanpa badge tambahan.

2. **DILARANG KERAS Menggunakan Badge Count Number**:
   - Jangan pernah menambahkan badge angka hitungan (*badge count number*), misalnya badge counter jumlah item pada tab navigasi, label counter di samping judul, badge notifikasi jumlah baris, dsb.

3. **Gaya Penataan & Diferensiasi Visual yang Disukai**:
   - Prioritaskan penataan urutan/posisi data (misal data hari ini ditaruh di paling atas).
   - Gunakan pewarnaan baris yang elegan (contoh: latar `bg-amber-50/90` dengan border kiri `border-l-4 border-l-amber-500`).
   - Jaga tampilan tetap bersih, rapi, dan profesional tanpa elemen dekoratif berlebihan seperti badge pill teks atau counter badge.
